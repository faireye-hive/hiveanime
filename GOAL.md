# Seek project goal

## Goal

Make Seek a modern, multilingual anime discovery and watch-tracking site with Hive Keychain sign-in and a safe demo account.

## Current milestone: modernize the UI and move to Vite

- [x] Refresh the visual design with neutral light and dark themes while keeping the app responsive.
- [x] Keep discovery, personal lists, episode progress, list/grid modes, and PT/EN/ES language selection.
- [x] Preserve Hive Keychain sign-in and demo mode.
- [x] Move source code into Vite's `src/` structure and serve the catalog from `public/`.
- [ ] Review the updated app in the browser and refine any issues found.
- [ ] Plan persistent, cross-device list storage for signed-in accounts.
