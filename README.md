# Seek

Seek is an anime catalog and watch-list app. The catalog is stored in `public/anime.json`; watch progress and preferences are saved in the browser. Sign-in supports Hive Keychain and a local demo account.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Vite writes the production site to `dist/`.
